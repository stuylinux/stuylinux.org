## Main Points Of Linux
We know some of you might be wondering why we use Linux. Here are some of the main reasons Matthew and Axel thought of.


### Freedom -> Control
- You know (or can get to know) everything on your computer, from where it is to how it works. 
- If something isn't working quite right, or you just want a certain feature, you can do all the fixing/changing yourself, since you actually know what is happening.


### Variety <-> Customization
- For 1 job, there are tons of different tools that have different benifits. This means it can please different tastes.
- For example, some people like their graphical user intercace (GUI) minimal, so they might use DWM and have a fast and quick window manager. On the other hand, some poeple like a pretty GUI, so they might use hyprland to make it pop. Others might want something with little setup, so they might use a desktop environment like Gnome.


### Security & Transparency
- If software is community driven, then there can be faster fixes to vulnerabilities. 
- For example, when there was a big `xz` vulnerability, the devs quickly fixed it up so people stayed secure.
- This also means the community reviews the software. If there is any sus stuff going on in the code, the community will likely call it out, especially if more people are using it.


### Performance + Longevity
- A lot of old computer get thrown out; e-waste is very prevalant. Linux has a lot of support for these older computers, so you can easily put them to good use.
- For example, Axel had an old thinkpad that came with windows on it. It was super slow. After he put Linux on it, it got much better, very usable.



## Distros
Linux is the very base of the computer, it manages what runs and how it runs. However, more things are needed to make a system.
You need a GUI, a package manager (something to manage what you install), default configurations (how stuff looks and acts), and default software

There are many popular distros, here are some of the most popular:
- **Ubuntu**: huge community, good for beginners, very widely used
- **Linux Mint**: Windows like, easy to transition to from Windows
- **Arch**: DIY, customizable, a learning opportunity, a meme (I use arch btw)
- **Gentoo**: source-based, extreme control (very hard, not for beginners)
- **ElementaryOS**: polished look, similar to macOS feel
- **Bazzite**: immutable (hard to mess up, like your phone's system), optimized for gaming
- **Tails**: privacy focused, focus on anonymity
- **NixOS**: reproducable on different machines
